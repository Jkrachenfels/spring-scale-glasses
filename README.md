# Spring scale for Meta Ray-Ban Display

An interactive isometric figure of a spring letter scale that shows Hooke's law, sized as a 600 × 600 Web App for Meta Ray-Ban Display glasses.

- Swipe up or right on the Neural Band to move a 100 g weight onto the pan; swipe down or left to take one off; tap to start or stop the tour.
- Each weight shortens the 245 N/m spring by m·g/k = 4.0 mm; the readout and dial come from the same model.
- On a computer, the arrow keys, Enter and 0–5 do the same.

Live page: https://jkrachenfels.github.io/spring-scale-glasses/

Educational demo. Not made by or affiliated with Meta. It collects no data and makes no network requests.
